# robots-ai.txt
#
# Everything on The Podium is meant to be found - that's the whole point of a
# leaderboard - so this mirrors the wide-open policy in /robots.txt
# (see app/robots.ts), just spelled out explicitly for AI crawlers/assistants
# by name in case any of them check here before falling back to a bare `*`.
#
# Most robots.txt parsers only apply the single MOST SPECIFIC User-agent
# block that matches a given bot - they do not merge a named block with the
# `*` block below it. So the two real disallows (see app/robots.ts for why
# they exist: /manage/ URLs embed a secret token in the path, /admin is a
# gated admin page) are repeated on every named block here, not just on `*`.
#
# See also /llms.txt for a plain-language summary of the site for AI
# assistants, and /sitemap.xml for the full page list.
